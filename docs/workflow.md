# Drupal upgrade workflow

This page is retained for existing links. The current operational guide is [Upgrade workflow](upgrade-workflow.md).

`drup` uses a durable project-local run record, checkpoint evidence, backups, and independent validation to coordinate major upgrades. The repository implementation—not a historical roadmap or an agent transcript—defines the action currently permitted.

- For the lifecycle and operator decision points, read [Upgrade workflow](upgrade-workflow.md).
- For persistence and authority boundaries, read [Architecture](architecture.md).
- For backup, restore, locked mode, and recovery, read [Safety and recovery](safety-and-recovery.md).
